# Instructions pour créer le repository GitHub

## Étape 1: Créer le repository sur GitHub

1. Allez sur https://github.com
2. Cliquez sur **+** → **New repository**
3. Nom du repository: `tontine-management-elite`
4. Description: `Système de gestion de tontines moderne et sophistiqué - Projet INF2212 - Université de Yaoundé I`
5. Choisissez **Public**
6. NE cochez PAS "Add a README file" (nous en avons déjà un)
7. Cliquez sur **Create repository**

## Étape 2: Connecter le repository local

Une fois le repository créé sur GitHub, exécutez ces commandes :

```bash
# Ajouter le remote (remplacez VOTRE_USERNAME par votre nom d'utilisateur GitHub)
git remote add origin https://github.com/VOTRE_USERNAME/tontine-management-elite.git

# Pousser le code sur GitHub
git push -u origin main
```

## Étape 3: Vérifier

Le projet sera disponible à l'adresse:
`https://github.com/VOTRE_USERNAME/tontine-management-elite`
